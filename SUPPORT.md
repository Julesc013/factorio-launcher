# Support

FacMan is in rapid pre-public development and has no published supported
release yet. Please use GitHub issues for reproducible defects, documentation
problems, and feature requests. Include the exact FacMan commit/version,
platform, package profile, provider identities when available, reproduction
steps, and redacted diagnostics.

Do not post vulnerabilities, credentials, paid Factorio content, or personal
data in a public issue. Follow [SECURITY.md](SECURITY.md) for private security
reporting.

Support claims are release-specific. The current source tree, CI artifacts,
historical checkpoints, unsigned previews, and autonomous alpha evidence do
not imply stable support. The authoritative rules are documented in
[the support policy](docs/release/SUPPORT_POLICY.md) and, once releases exist,
their append-only ledger entries.
