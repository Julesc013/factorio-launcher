# Revalidation-04 changed files

project truth, generated plan views, README status, and permanent
qualification/revalidation checkpoints.

candidate policy, runtime execution, schemas, WPR profiles, permits, or route
authority. Machine-local qualification and stage outputs remain outside the
repository and are not copied into product packages.
