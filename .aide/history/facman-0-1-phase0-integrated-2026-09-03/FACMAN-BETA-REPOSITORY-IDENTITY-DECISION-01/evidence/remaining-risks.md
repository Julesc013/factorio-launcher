# Remaining risks

- The GitHub branch ruleset still advertises merge, squash, and rebase even
  though repository-level settings currently enable normal merge commits only.
- GitHub requires zero approvals; independent assurance and the human
  integration decision remain programme-policy obligations rather than a
  one-approval machine rule.
- Beta, RC, and stable tag namespaces are not protected yet.
- Alpha.6 workspace recovery, managed installation, real Play, human native
  GUI acceptance, signing, publication, and support remain incomplete.

These risks transfer to `FACMAN-BETA-RULESET-AND-TAG-PROTECTION-01` and the
subsequent Alpha.6/Alpha.7 WorkUnits. None is silently promoted here.
