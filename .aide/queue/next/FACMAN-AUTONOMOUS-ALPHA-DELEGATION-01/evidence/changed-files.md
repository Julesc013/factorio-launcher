# Changed-file classification

This planned, non-authorizing WorkUnit contains the ratified programme doctrine
and its mechanical enforcement surfaces:

- canonical version-train, autonomy, milestone, capability/frontend, withdrawal,
  component-maturity, branch-policy, and release-index truth;
- closed candidate, human-receipt, ledger-entry, and withdrawal schemas;
- validators, adversarial tests, CI routing, generated metadata, package naming,
  channels, dependency/SBOM projections, roadmap, TODO, README, and AIDE state;
- repository governance, support, architecture, product, and release documentation;
- a fail-closed repair binding observed provider commits and trees to the release
  provider lock.

The WorkUnit does not change route v1, route v2, the active route index, the
workspace lock, the provider lock, provider repositories, or product runtime
authority.
