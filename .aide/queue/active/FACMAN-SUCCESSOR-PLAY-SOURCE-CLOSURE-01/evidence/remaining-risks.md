# Remaining risks

- Final task-ref native source closure still requires a clean capable Windows
  host that can launch the complete native toolchain. The current managed host's
  `cmd.exe` child-process denial remains an external environment limitation.
- A local or hosted unit-test pass is not the immutable single-run closure
  record. The exact published task head must be reconstructed from empty roots.
- Task-ref closure is rehearsal evidence only. Canonical-ref closure must be
  repeated after reviewed integration and canonical promotion.
- Source closure grants no Factorio execution, observer, prepare, permit, Setup
  mutation, signing, publication, route capability, or route promotion.
- The checked-in route index keeps all three source-closure admission gates
  false. The hardened tool therefore refuses before provider cloning, archive
  hashing, building, or report creation until a separate reviewed authority
  transition changes live route-selection truth.
- Environment isolation rejects inherited Git, CMake, provider-root, compiler,
  cache, and loader injection and binds the exact proof helpers plus locked
  schema-validation dependency set. It does not make the host transitive or
  hermetic: PATH resolution, the operating-system loader, native SDK/toolchain
  installation, runner image, and Python interpreter still require a clean,
  independently qualified and immutable host-image identity.
