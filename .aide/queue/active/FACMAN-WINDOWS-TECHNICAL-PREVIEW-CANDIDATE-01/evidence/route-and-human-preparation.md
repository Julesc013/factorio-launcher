# Factorio 2.1.14 route and human preparation

Factorio 2.1.14 build 87180 is retained only as prior engineering evidence. It
reached the main menu under the default-off FacMan harness and preserved the
foreign archive inventory, but the source/package identities are noncanonical
for this candidate and no release route or current human verdict is accepted.

The integrated non-authorizing scaffold now supplies a closed schema-valid
2.1.14 route packet, exact future action sequence, negative-control validator,
and a generic schema-valid human UX/accessibility receipt template defaulting
every journey to Inconclusive. It reserves a fresh `.03` evidence family while
leaving candidate, host, source custody, execution authority, and human verdict
unassigned. The existing immutable 2.0.77 route contracts remain untouched.

Actual launch observation still requires a resettable Windows proof host,
read-only custody of the private archive, explicit D3 execution authority, and
a later D4 human verdict. Those scoped gates do not block product repair,
canonical package construction, route scaffolding, or human-packet preparation.
