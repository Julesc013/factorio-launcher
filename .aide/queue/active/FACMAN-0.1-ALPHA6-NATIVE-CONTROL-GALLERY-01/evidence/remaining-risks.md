# Remaining risks and boundaries

The WorkUnit closes its two canonical implementation criteria. The following
programme obligations remain open and must not be inferred from this result:

- genuine keyboard and screen-reader experience on release candidates;
- physical monitor DPI and desktop-theme transitions beyond toolkit fixtures;
- live Factorio, setup or mutable backend behavior;
- signing, publication, support, Beta or stable-release acceptance.

The qualified packaged input still identifies itself as the unsupported
private `0.1.0-alpha.5` candidate. Closing the gallery does not change that
version or authorize an Alpha.6 release.
