# FacMan 0.1.0-alpha.1

FacMan `0.1.0-alpha.1` is an unsupported, unsigned, unpublished Windows 10/11
x64 alpha candidate. It contains the normative CLI JSON interface, human CLI
diagnostics, the same-binary TUI, and the WinForms ordinary product journey.
Corrected release assets must bind the exact accepted source, ULK `1.9.1`, USK
`1.0.0`, three-root reproducibility, native integrity/drift controls, SBOM,
provenance, licences, and the applicable route evidence before any stronger
claim is made.

## Support and signing

This alpha is unsupported. Security reports and exact-build defects may be
triaged, but no response or backport window is promised. If the release-ledger
asset says the package is unsigned, publisher authenticity is not established;
verify every SHA-256 against the attached checksums before use.

## Known limitations

- Only exact qualified Windows 10/11 x64 portable packages are in scope. No
  real Factorio Play route is currently accepted.
- Formal WinForms and TUI human accessibility acceptance is deferred to the
  beta gate. The alpha does not claim beta usability or accessibility support.
- Managed Factorio installation, SteamCMD, network acquisition, self-update,
  servers, services, web access, macOS, Linux, and additional frontends are out
  of scope.
- FacMan never bundles Factorio. The user supplies a licensed installation or
  archive under the separately qualified route.

The current WorkUnit authorizes no tag or publication. A later tag-only alpha
requires corrected protected-dev integration and all canonical alpha tag gates;
a public downloadable alpha additionally requires an accepted real Play route,
complete assets, and separate publication authority.
