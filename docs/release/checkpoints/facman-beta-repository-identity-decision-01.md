# FacMan 0.1 repository identity freeze

Date: 3 September 2026 (AEST)

The canonical repository remains `Julesc013/factorio-launcher`, numeric GitHub
repository ID `1293124404`, for the complete 0.1 release train through stable
`0.1.0` publication and its post-release review. The product name remains
`FacMan`.

The possible future slug `Julesc013/facman` is not a current plan. A rename is
not authorized during Alpha, Beta, RC, or stable 0.1 work. Any later rename is
a separate migration programme with its own redirect, source, package,
provenance, documentation, automation, and support validation.

This freeze is low risk because product identity, repository role, network
locator, and local workspace name are already separate concepts in the
repository model. No GitHub setting or repository locator was changed.
