# FacMan 0.1.0-alpha.3 — unified cross-platform manual-test draft

Alpha.3 is a private, unsigned, unsupported prerelease for owner-directed
manual testing. It supersedes alpha.2's user-facing distribution shape without
rewriting or replacing the alpha.2 tag, source, or assets.

## What changed

- One portable product download and one setup download per platform.
- Every product package includes the native `FacMan` GUI and the `facman`
  terminal host.
- CLI JSON, human CLI, and TUI use the same terminal binary; start TUI with
  `facman tui`.
- WinForms, AppKit, and GTK remain internal implementation names and no longer
  appear in primary download names.
- Setup assets are self-contained and work offline; no payload ZIP sidecar is
  required.
- Checksums are one text file and detailed qualification records are one
  evidence ZIP.

## Downloads

Choose exactly one product package for the machine and desired mode:

| Platform | Portable, no installation | Setup |
| --- | --- | --- |
| Windows x64 | `FacMan-0.1.0-alpha.3-windows-x64-portable.zip` | `FacMan-0.1.0-alpha.3-windows-x64-setup.exe` |
| macOS 13+ Intel x64 | `FacMan-0.1.0-alpha.3-macos-x64-portable.zip` | `FacMan-0.1.0-alpha.3-macos-x64-setup.pkg` |
| Ubuntu 24.04 reference x64 | `FacMan-0.1.0-alpha.3-linux-x64-portable.tar.zst` | `FacMan-0.1.0-alpha.3-linux-x64-setup.run` |

Use `FacMan-0.1.0-alpha.3-SHA256SUMS.txt` before extraction or execution.
`FacMan-0.1.0-alpha.3-evidence.zip` is for audit and diagnosis, not ordinary
installation.

## How to test

1. Download from the authenticated draft release.
2. Verify the package SHA-256 against the checksum file.
3. For portable testing, extract into a new empty directory. Do not overwrite a
   previous extraction.
4. Start `FacMan` for GUI testing.
5. Start `facman --help`, a JSON command, and `facman tui` for terminal
   testing.
6. Test setup and removal separately from portable use.
7. Record the exact package filename, SHA-256, OS version, result, and notes.

On Windows, the portable GUI is `FacMan.exe` and the terminal host is
`bin\facman.exe`. They cannot safely share one directory because Windows
treats their case-only name difference as the same file.

## Setup effects

- Windows: current-user versioned install, Start Menu entry, HKCU uninstall and
  repair registration, receipts; no elevation or PATH change by default.
- macOS: installs `/Applications/FacMan.app` and
  `/usr/local/bin/facman`; authorization may be requested.
- Linux: current-user installation under `~/.local`, command links, desktop
  entry, installed-state, and maintenance receipts.

Setup never installs or modifies Factorio. Uninstall must preserve FacMan
workspaces, Factorio installs, saves, mods, and all non-owned content.

## Known limitations

- All binaries and packages are unsigned.
- The macOS app and PKG are not notarized.
- Windows 10 22H2 and Windows 11 x64 are the 0.1 support direction.
- macOS is Intel x64 only; Apple Silicon and universal binaries are absent.
- Linux is limited to the Ubuntu 24.04 x64 GTK 3/X11 reference environment.
- No automatic updater, public support promise, or stability guarantee.
- Real-Factorio execution remains separately gated and is not authorized by
  this release.
