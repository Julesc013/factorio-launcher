# Planning archive

This directory preserves superseded planning corpora for searchability and
decision archaeology. Files here are not executable backlogs and must not be
used to infer current scope, status, priority, ownership, or implementation
authority.

The canonical plan is `release/index/plan.v1.toml`. Its operational views are
the generated root `todo.md` and `docs/roadmap/current.md`.

## Archived documents

- `facman-platform-refactor-plan-2026-07-28.md` — the full 2,483-line
  architecture, classic-shell, refactor, cross-repository, research, and
  improvement corpus assembled from the first two reports. It remains the
  source for future extraction, but none of its 612 checklist entries becomes
  active merely by being present.

When an archived idea is revived, create a bounded epic or work unit in the
canonical plan with a current owner, release, outcome, dependency set, evidence
requirement, and explicit scope substitution.
