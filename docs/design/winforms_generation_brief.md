# WinForms successor generation brief

Status: non-authoritative rendering and fixture reference

This brief helps humans, deterministic generators, mockup tools, and optional
AI systems visualize the ratified Windows Classic profile. It is not a source
layout mandate, contract, package definition, support claim, WorkUnit
activation, or authority grant.

Canonical meaning remains in the human-interface constitution, Windows
Classic product profile, WinForms architecture, canonical plan, and
machine-readable release records. Generated images and code are proposals
until ordinary review, tests, and qualification accept them.

## Visual direction

- System Native Windows Forms controls and behavior.
- Restrained OEM+ identity through iconography, spacing, and semantic accents.
- Explorer/MMC-style global navigation rather than permanent peer TabPages.
- One compact Launch Deck and one ordinary primary action.
- Plain-language readiness, with explanation, remedy, and technical evidence
  disclosed in that order.
- Standard and Compact layout fixtures.
- No custom chrome, executable theme, arbitrary widget extension, or embedded
  web shell.

## Required fixture states

```text
no instance selected
ready
refused with one actionable remedy
refreshing while prior coherent snapshot remains visible
running
ordinary exit and Last Run
interrupted with recovery available
stale snapshot with dependent actions disabled
compact 800x600-class effective layout
100%, 150%, and 200% DPI
High Contrast
pseudo-localized long labels
keyboard-only navigation
```

## Generation constraints

- Use only fake product identities and fixture data.
- Do not depict Play, Setup, publication, or signing as already authorized.
- Preserve exact refusal, operation, recovery, and freshness truth.
- Do not turn Settings, Accounts, Evidence, or Advanced into peer product
  roots merely to fill navigation.
- Do not create `Xp`, `Vista`, or `Win7Plus` source families.
- Do not label an operating system supported from a mockup or compile result.
- Do not generate credentials, network calls, permits, installers, signatures,
  or release artifacts.

## Review use

Compare proposals by semantic coverage, compact behavior, keyboard order,
accessibility, platform convention, disclosure quality, and preservation of
one primary action. Pixel resemblance to this wireframe is not an acceptance
criterion.
